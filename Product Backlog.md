# Product Backlog

## User requirements: 
  - Sign in with Google
  - Check menu to:
    - Add Category
    - Add items on a Category
    - Login/Sign Up 
    - Start a bracket challenge for the category
      - Get to choose the number of items completing 32, 16, 8, ...
      - Items randomly picked from the category's pool for the bracket challenge
      - Show an error message if number of items in the pool is not enough for bracket challenge choosen
    - Vote for a Challenge
      - See a countdown timer for each active match (layer 1/32, 1/16, ...)
      - See the overall movment of items to the top
      - Watch vote counts update live
 
  - See Previous weeks winner
